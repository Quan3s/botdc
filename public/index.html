    🧩 Thêm plugin

    Dán link raw script (http/https). Script sẽ tự lưu vào GitHub Gist và load ngay, không cần deploy lại.

    API trong script: api.get/post(...), api.command('ten', fn), api.kv, db, crypto, fetch.
    Web: /plugin/<id>/<path> · Discord: /plugin ten:lenh
